OmniFood – Responsive Food Delivery Landing Page

This is my assignment for the TuteDude MERN Stack course. The task was to recreate a single-page landing website for a food delivery brand called OmniFood, using only HTML and CSS. I mostly wanted to get better at CSS layouts (flexbox and grid) and making a page look right on different screen sizes.

How to run
Download or clone the project.
Open the folder in VS Code.
Right-click index.html and choose Open with Live Server. You can also just double-click the file to open it in the browser.

You need internet for the Google font, Font Awesome and the Ionicons to load.
